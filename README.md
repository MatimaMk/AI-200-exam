# AI-200 Practice

A single-page practice site for the Microsoft AI-200 exam (Developing AI Cloud Solutions on Azure).

- Full timed practice exam (40 questions, 60 minutes, 70% pass mark) with mark-for-review and a question navigator
- Practice by topic, grouped under Containers, Data for AI, Using Azure services, and Security and monitoring
- Four question formats: multiple choice, choose more than one, drag to order, drag to match
- Scores and missed questions are saved in the browser (localStorage)

All questions are original and written against the public AI-200 skills outline. This is an unofficial study aid and is not affiliated with Microsoft.

## Run it

Open `index.html` in a browser. No build step or dependencies.

## Host it on GitHub Pages

Repository Settings > Pages > Deploy from a branch > `main` / root.
